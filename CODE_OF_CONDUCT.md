# DVM Code of Conduct

DVM adopts the [Linux Foundation Code of Conduct](https://lfprojects.org/policies/code-of-conduct/).
It applies to everyone participating in DVM, including in issues, pull requests, code reviews,
and community meetings.

Treat fellow participants with respect. Give feedback on the work and explain technical
disagreements constructively. Harassment, bullying, and discrimination have no place in the
DVM community.

To report an incident or appeal a report, follow the **Incident Procedure** in the
[official code](https://lfprojects.org/policies/code-of-conduct/).
